# DATOS

Conference site for **DATOS**, the [Data Engineering Pilipinas](https://dataengineering.ph) event.

This repo ships the **beta** design as the main site (`/`).

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Local server at `http://localhost:4321` |
| `npm run build` | Production build to `./dist/` |
| `npm run preview` | Preview the production build |

## Stack

Astro static site. Content lives in `src/content/`; UI in `src/designs/beta/`.
